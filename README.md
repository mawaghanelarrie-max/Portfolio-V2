# Portfolio V2 — Ellarie Alane

Base de portfolio professionnel pour BTS SIO option SISR.

## Installation

```bash
npm install
npm run dev
```

Puis ouvrir l'URL locale affichée par Vite.

## Pages incluses

- Accueil
- Profil
- Compétences avec barres de progression
- Projets
- Veille technologique
- Contact

## Veille

Thème :
**Vers des réseaux autonomes : quel avenir pour l’administration réseau ?**

Axes :
- IA appliquée aux réseaux
- Automatisation de l’administration réseau
- SDN et virtualisation
- Cloud, 5G et 6G
- Zero Trust et cybersécurité
- Impact sur le métier d’administrateur systèmes et réseaux
